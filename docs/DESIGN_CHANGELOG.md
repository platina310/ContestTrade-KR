# 설계 변경 로그

2026-05~06은 파일럿에 쓴 **개발(dev) 구간**이다. 이후 설계를 바꿀 때마다 한 줄씩 추가한다.

유형 구분
- **정합성**: 수익률과 무관하게 "데이터·규칙이 사실과 맞는가"로 판단한 수정 → 스누핑 아님
- **설계**: 성과를 보기 전에 구조적 이유로 정한 것
- **성과 기반**: 파일럿(또는 백테스트) 성과를 보고 바꾼 것 → 본 실험에서 dev 구간 제외 결과를 함께 보고
